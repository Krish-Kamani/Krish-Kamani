### 👨‍💻 About Me

I'm a **Computer Engineering student** passionate about understanding how systems work — from low-level kernel interfaces and hardware up to modern reactive user interfaces.

- 🔭 **Currently Building**: Local-first applications, desktop utilities with **Tauri & Electron**, and system-level tools in **C/C++**.
- 🐧 **Operating System**: Daily driving **Arch Linux** and tinkering with system customization & automation.
- 🔐 **Core Interests**: Security & cryptography (AES-GCM, zero-knowledge data stores), low-level Linux programming (`procfs`, POSIX calls), and terminal developer tooling.
- 🎯 **Engineering Philosophy**: *"Finish things. Small complete projects teach more than large abandoned ones. Read the source."*
